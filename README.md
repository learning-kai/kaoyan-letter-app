# 考研英语一小作文背诵网站（完整版）

基于学习科学（主动回忆、FSRS-5 间隔重复、4 步渐进撤除提示、错误驱动复习、交错练习、生成效应）构建的考研英语一小作文纯静态背诵应用。

## 已完成全部功能（第一至第四阶段）

1. **数据逐字转录与校验**：严格逐字转录《小作文_最终背诵版.md》全部 7 套模板（建议信、邀请信、通知、道歉信、感谢信、介绍类、备用祝贺信）、逐句中文、故事线、首词链与万能填充词表；共用句严格去重。
2. **核心算法与 24 项单元测试**：
   - `normalize.ts` / `diff.ts` / `grader.ts`：中英文标点规范化、多余空格合并、大小写单独提示不扣分、框架模式槽位通配、实填模式词性启发校验、拼写（Levenshtein ≤ 2）与词形错误识别（如 `break` / `breaking`）。
   - `scheduler.ts` / `cards.ts`：FSRS-5（`ts-fsrs`）、4 档间隔预览、交错排布、Again 本轮 3–5 张后重排、考前 ≤ 30 天间隔上限与考前 3 天冲刺队列、5 类扩展卡片（P 短语 / F 词性 / O 排序 / T 识别 / E 整篇）解锁逻辑。
3. **全部 8 个页面**：
   - **今日（Today）**：问候与考试倒计时、考前 3 天冲刺入口、今日任务卡片（含预计用时）、9 课解锁进度条（第 9 课默认折叠）、近 7 天练习热力图。
   - **学习（Learn）**：4 步渐进撤除提示（理解 5 秒 → 首词提示 → 60% 实词挖空 → 只看中文），准确率 < 90% 退回上一步。
   - **复习（Review）**：专注模式隐藏侧栏，支持打字模式与纸笔模式（Space 显答案 + 1–4 自评）、框架/实填切换、错题/冲刺队列与 P/F/O/T/E 扩展卡片专项训练。
   - **实战（Exam）**：21 道原创模拟题（每类 3 道，含 6 道易混题），20 秒限时判型 → 15 分钟计时（10 分钟目标）信纸套写 → 逐句模板对齐复盘。
   - **错题本（Mistakes）**：自动收录近 30 天 Again 或错误率 > 30% 的句子，展示高频错词统计，支持「只练错题」。
   - **统计（Stats）**：各模板掌握度横向分段条、未来 14 天复习量预测柱状图、整篇实战用时折线图（含 10 分钟目标线）、题型识别正确率（Recharts，严格遵循设计令牌配色）。
   - **模板库（Library）**：信纸排版、槽位词性/填充词浮层、逐句朗读、掌握度圆点、仅看骨架/仅看主体/中文开关、可搜索万能填充词表、首词链视图。
   - **设置（Settings）**：考试日期、每日新句上限、目标保持率、默认输入/槽位模式、严格标点、解锁全部、浅色/深色/跟随系统主题、正文字号、JSON 备份导出/导入与输入「重置」二次确认清空。
4. **PWA 离线与细节**：集成 `vite-plugin-pwa` 离线缓存、自托管 Fontsource 字体、全局键盘快捷键及 `?` 快捷键弹窗、响应式三端布局（桌面三栏 / 平板图标栏 / 手机底部 5 项标签栏）。

## 内容疑点（未修改原文，仅作记录）

按铁律，以下 4 处均与《小作文_最终背诵版.md》保持逐字一致：

1. **通知首段第 1 句**：`We greatly appreciate all students for sparing their precious time to pay attention to this notice.` — 标准英语中 `appreciate` 通常直接接动名词或 `sb.'s doing`，而 `thank sb. for doing` 才接 `for`。
2. **建议信主体第 2 句**：`you are advised to [建议行动] around [题目相关词]` — `around` 与部分动词短语搭配略偏中式。
3. **邀请信主体第 3 句**：`especially in the light of [主题]` — 美式常见 `in light of`，英式可用 `in the light of`。
4. **介绍类主体第 1 句**：首句以槽位 `[题目相关词]` 开头，其首词链写作 `First and foremost, … refers to`，已按原文保留。
